PROJECT 01 · Python

학교 공지 브리핑 봇

학교·학과 공지와 청년정책을 모아 핵심 정보를 정리하고, 사용자 설정에 맞는 정보를 디스코드와 웹페이지로 제공하는 프로젝트입니다.

GitHub 저장소 보기

프로젝트 개요

학교 공지와 학과 공지가 여러 게시판에 흩어져 있어 필요한 정보를 직접 찾아야 하는 불편을 줄이기 위해 시작했습니다. 공지 수집부터 AI 정보 정리, 사용자 설정에 따른 관련도 계산, 디스코드 브리핑과 웹페이지 표시까지 이어지는 자동화 시스템을 만들었습니다.

주요 기능

  • 학교 일반·장학·학사 공지와 설정된 학과의 게시판 공지를 수집합니다.
  • 공지의 대상, 분류, 마감일과 준비물 등 주요 정보를 AI로 정리합니다.
  • 사용자 설정을 바탕으로 공지 관련도와 판단 이유를 표시합니다.
  • 디스코드 아침 브리핑과 웹페이지에서 공지를 확인하고 원문으로 이동할 수 있습니다.
  • 온통청년 API에서 청년정책을 수집해 공통 공지 데이터 형식으로 변환합니다.

구현 내용

Python의 requests와 BeautifulSoup을 사용해 학교·학과 게시판의 제목, 게시일, 링크, 본문과 이미지 주소를 수집했습니다. 공지 ID를 기준으로 기존 데이터와 새 데이터를 병합하고, 본문이 비어 있는 기존 공지는 다시 수집하도록 처리했습니다. 수집 결과는 JSON으로 저장해 AI 정리와 관련도 계산 단계에서 함께 사용할 수 있도록 구성했습니다.

GitHub Actions로 자동 실행 흐름을 구성하고, 온통청년 API 수집 모듈도 구현했습니다. 로컬 실행에서 API 응답 961건 중 조건에 맞는 정책 77건이 저장되는 것을 확인했습니다.

생활관과 반도체·디스플레이공학과 게시판은 기존 게시판과 도메인 및 페이지 구조가 달라 별도 수집 로직과 검증이 필요해 후속 과제로 남겼습니다.

내 역할

공지 수집 파트를 맡아 학교 게시판과 사용자 프로필의 학과에 맞는 학과 게시판을 수집하도록 구현했습니다. 기존 공지는 유지하면서 새 공지를 ID 기준으로 추가하고, 저장된 본문이 있는 공지는 다시 요청하지 않으며 본문이 비어 있는 공지는 재수집해 채우도록 개선했습니다.

또한 온통청년 API 수집 모듈을 작성해 청년정책을 프로젝트의 공통 JSON 형식으로 변환했습니다. API 키와 지역 설정에 따른 요청, 대상 정책 선별, 전국 대상 정책의 지역 코드 처리도 반영했습니다.
