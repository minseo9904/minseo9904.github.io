PROJECT 01 · Python

학교 공지 브리핑 봇

학교·학과 공지와 청년정책을 모아 핵심 정보를 정리하고, 사용자 설정에 맞는 정보를 디스코드와 웹페이지로 제공하는 프로젝트입니다.

GitHub 저장소 보기

프로젝트 개요

학교와 학과별로 흩어진 공지를 직접 확인해야 하는 번거로움을 줄이기 위해 시작했습니다. 공지 수집부터 AI 정보 추출, 사용자 설정에 따른 관련도 계산, 디스코드 브리핑과 웹페이지 표시까지 연결했습니다.

주요 기능

  • 학교 일반·장학·학사 공지와 설정된 학과의 게시판 공지를 수집합니다.
  • AI가 공지의 대상, 분류, 마감일, 준비물, 추가 일정 등의 정보를 추출합니다.
  • 프로필 설정과 공지 대상을 비교해 관련도 별점과 판단 이유를 표시합니다.
  • 디스코드 아침 브리핑에서 날씨, 새 공지, 마감 임박 공지를 확인하고 원문으로 이동할 수 있습니다.
  • 웹페이지에서 공지를 분류별로 확인하고 관련도순·마감순으로 살펴볼 수 있습니다.
  • 온통청년 API를 활용해 청년정책을 수집할 수 있도록 확장했습니다.

구현 내용

Python의 requests와 BeautifulSoup으로 웹 게시판의 공지 정보를 수집하고, 온통청년 API에서도 정책 데이터를 가져옵니다. 수집한 데이터는 공통 JSON 형식으로 저장해 AI 정보 추출과 관련도 계산에 전달합니다.

AI는 공지 본문과 이미지 정보를 바탕으로 대상, 마감일, 준비물 등을 정리합니다. 관련도 계산 모듈은 정리된 공지 정보와 사용자 프로필을 비교해 별점과 이유를 계산합니다.

GitHub Actions가 정해진 시간에 수집과 분석, 디스코드 전송 작업을 실행합니다. 결과는 Discord Webhook으로 전달하고, GitHub Pages 웹페이지에서도 확인할 수 있도록 구성했습니다.

내 역할

공지 수집 파트와 청년정책 수집 기능을 맡았습니다. requests와 BeautifulSoup을 이용해 학교 게시판의 제목, 게시일, 링크, 본문, 이미지 주소를 수집하고, 프로필의 학과에 맞는 학과 게시판만 선택하도록 크롤러를 보완했습니다.

기존 공지는 유지하고 새 공지를 ID 기준으로 추가하도록 했으며, 본문이 이미 저장된 공지는 다시 요청하지 않도록 처리했습니다. 기존 공지의 본문이 비어 있을 때는 재수집해 채우고, 새 공지에는 수집 시각과 새 공지 표시를 저장하도록 개선했습니다.

온통청년 API 수집 모듈도 구현해 정책 데이터를 프로젝트의 공통 JSON 형식으로 변환했습니다. 지역 조건과 전국 대상 정책의 지역 코드 처리 등을 반영하고, 로컬 실행으로 API 데이터가 조건에 맞게 저장되는지 확인했습니다.
